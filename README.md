# AIDC ESS 요구사항 (AIDC ESS Requirements)

## 개요

본 저장소는 **AI 데이터 센터(AIDC, AI Data Center)**에서 요구하는 **ESS(Energy Storage System, 에너지 저장 시스템)** 요구 사항을 정리한 자료입니다.

AI 데이터 센터는 대규모 AI 연산을 위해 안정적이고 고밀도의 전력 공급이 필수적이며, ESS는 전력 안정화, 비상 전력 공급, 피크 전력 저감 등의 역할을 수행합니다.

## 주요 요구 사항 요약

| 구분 | 항목 | 기준 |
|------|------|------|
| 전력 | 공급 전압 | AC 380V / DC 1500V |
| 용량 | 최소 용량 | 랙 당 20–100 kWh |
| 수명 | 사이클 수명 | 3,000 사이클 이상 (80% DoD 기준) |
| 안전 | 인증 | UL 9540, IEC 62619, KC 인증 |
| 통신 | 프로토콜 | Modbus TCP / CAN / SNMP |
| 환경 | 동작 온도 | 0–40°C |

## 관련 표준 및 규격

- **IEC 62619**: 이차전지 안전 요구사항
- **UL 9540**: 에너지 저장 시스템 표준
- **NFPA 855**: ESS 설치 기준
- **IEEE 1547**: 분산 에너지 자원 연계 표준
- **KC 62619**: 국내 이차전지 안전 기준
